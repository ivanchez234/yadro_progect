# 🎙️ YADRO_streamer

**YADRO_streamer** — это высокопроизводительное десктопное приложение для интеллектуального воспроизведения аудио. Основная архитектурная особенность проекта — интеграция кастомного C++ плагина для GStreamer, который в реальном времени анализирует аудиопоток и вырезает тишину (Voice Activity Detection), сохраняя естественное звучание речи.

## ✨ Ключевые возможности

* **Real-time VAD:** Детектирование и удаление тишины «на лету» без предварительной обработки файла.
* **Алгоритм Hangover:** Умное «послесвечение» (~210 мс) искусственно удерживает окно записи открытым, что предотвращает проглатывание окончаний слов при резком обрыве речи.
* **Динамическое управление:** Изменение агрессивности вырезания тишины и скорости воспроизведения (Pitch) прямо во время звучания без остановки или перезапуска медиа-конвейера.
* **Живая телеметрия:** Сбор статистики о вырезанных кадрах и расчет процента сжатия аудиофайла через асинхронную шину сообщений (GstBus).
* **Современный UI:** Темная тема интерфейса (Dark Mode), разработанная на базе Qt 6 с использованием QSS.

## 🛠 Технологический стек

* **Ядро & Плагин:** C++17, GStreamer 1.0, GObject / GLib, libfvad.
* **Интерфейс:** Qt 6 (Widgets, Signals & Slots).
* **Сборка:** CMake, Pkg-config.
* **Система валидации:** Python 3.12, PyTorch, Torchaudio, нейросеть Silero VAD.

## 🏗 Архитектура

Проект построен по монолитной модели. Графический интерфейс на Qt напрямую управляет мультимедийным конвейером GStreamer. 

Низкоуровневая обработка аудио реализована в виде независимой разделяемой библиотеки `libgstyadrovad.so`, работающей как конечный автомат. Плагин буферизует звук строгими чанками по 30 мс (960 байт), классифицирует их (SPEECH/SILENCE) и динамически пересчитывает временные метки (Presentation Time Stamps) для обеспечения идеальной бесшовной склейки оставшихся фрагментов.

## 📖 Руководство пользователя

Приложение спроектировано так, чтобы скрыть сложную математику конвейера за интуитивно понятным интерфейсом. Рабочий процесс состоит из трех этапов:

### 1. Инициализация и выбор файла
При старте система автоматически проверяет готовность движка GStreamer. Нажмите кнопку **«Выбрать файл»** для загрузки аудио (поддерживаются форматы `.wav`, `.mp3` и др.). Если в этот момент проигрывался другой трек, система безопасно остановит его и очистит память.

### 2. Управление в реальном времени (Real-time)
Все параметры можно изменять прямо во время воспроизведения, не ставя трек на паузу:
* **Агрессивность VAD (0 – 3):** * *Уровни 0-1 (Щадящий):* Вырезаются только длинные паузы. Идеально для сохранения естественных вздохов и микропауз.
  * *Уровень 2 (Сбалансированный):* Оптимальное удаление фонового шума и пауз между предложениями (По умолчанию).
  * *Уровень 3 (Агрессивный):* Максимальное сжатие, удаление пробелов между отдельными словами.
* **Скорость (x0.5 – x2.0):** Управление темпом (Pitch) без искажения высоты голоса.

### 3. Аналитика и отчетность
Интерфейс транслирует состояние ядра в окно логов (правая часть экрана). При завершении воспроизведения трека срабатывает система телеметрии, выводящая итоговый отчет:
* Исходная длительность аудиофайла.
* Итоговая длительность после удаления тишины.
* **Процент сжатия** (эффективность экономии времени).
